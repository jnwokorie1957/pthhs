## Current primary guidance

Reviewed October 19, 2026:

- Google recommends fixing a failed sitemap and submitting a new request when
  repeated fetch attempts have stopped. A successful read is distinct from
  indexing. That supports this one request after the verified XML repair.
  [Sitemaps report](https://support.google.com/webmasters/answer/7451001?hl=en)
- Sitemaps assist discovery without guaranteeing crawl or indexing of each URL.
  [Sitemap overview](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview)
- Titles should accurately and concisely describe each page; rewriting them
  without a demonstrated issue is not an outcome measurement method.
  [Title guidance](https://developers.google.com/search/docs/appearance/title-link)
- The Core Web Vitals report uses real-user data and can omit groups without
  sufficient reporting samples. Local checks do not substitute for those metrics.
  [Core Web Vitals report](https://support.google.com/webmasters/answer/9205520?hl=en)
