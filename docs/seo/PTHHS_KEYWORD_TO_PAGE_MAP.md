# PTHHS Keyword-to-Page Mapping
**Date:** 2026-08-19  
**Purpose:** Assign each primary keyword cluster to a dominant target URL to prevent cannibalization and maximize ranking potential.

---

## MAPPING PRINCIPLES

1. **One dominant target URL per primary keyword cluster** — prevents internal competition
2. **Secondary keywords assigned to supporting pages** — creates topical authority without cannibalization
3. **Current rank documented** — baseline for measuring improvement
4. **Target rank set** — realistic 90-day goals based on competitor analysis
5. **Search intent matched** — transactional pages for high-conversion keywords, informational for eligibility
6. **Conversion CTA defined** — every money page has a clear next step (call, form, eligibility check)
7. **Supporting pages identified** — internal linking structure to reinforce topical authority
