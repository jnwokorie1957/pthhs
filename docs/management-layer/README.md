# PTHHS Management Layer

The internal `/primetime` product has two coordinated sources of truth:

- [`DEVELOPER_TASKS.md`](DEVELOPER_TASKS.md) owns code, integration, security,
  deployment, testing, data, and observability work.
- [`OWNER_OPERATIONS_TASKS.md`](OWNER_OPERATIONS_TASKS.md) owns real operating
  rules, permissions, approvals, thresholds, messaging, and acceptance.

Do not unblock a developer item by inventing an owner decision. Do not mark an
owner item complete without explicit confirmation or verifiable evidence.
