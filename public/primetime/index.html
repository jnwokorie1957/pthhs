Operational records

Queries are read-only. Billing amounts are not cash collections; source actual/pay/adjusted hours remain separate. No inference is made from absent values. Reference catalogs describe available codes and statuses, not live balances, tax liabilities, claims or collections.

Create caregiver rate

Create a separately reviewed rate after verifying the caregiver's office and discipline. Existing overlapping rates require separate policy review. Dates and amounts are explicit; this does not execute payroll.

In-service topic creation

Create a training topic for the configured office. Explicitly review whether it counts toward compliance. This creates reference metadata; it does not certify caregiver attendance or eligibility.

Create availability for review

Requires one verified caregiver office and seven explicitly entered days. Existing permanent availability or overlapping special periods require separate review. Blank days and overnight intervals are unavailable pending vendor clarification. This records preferences; it does not assign a shift.

Internal patient operational note

Prepare a general operational note for independent review. Internal is fixed to Yes, emergency priority to No, and no email recipient is sent. Service or schedule changes need a separate workflow. This does not certify clinical care or change an authorization.

Patient contract identity review

Propose an alternate patient ID for an existing contract placement. Verify the payer-facing identity before review. Primary status, service dates, service codes and discharge fields are preserved. Submission requires independent review and a separate release gate.

Review a billed-visit collection note

This changes collection, claim and follow-up information. It does not record a payment or collected cash. Select explicit IDs from the corresponding reference reads, review the existing notes and verify collection authority. Other charges are outside this workflow; submission stays disabled until deployment approval.

Create a non-skilled linked schedule

Explicit assignment requires independent scheduling review. This limited flow rejects any other schedule for either person on the selected or adjacent days. It does not establish clinical eligibility, authorization balance or notification behavior; verify these in the authority record. Readback does not expose persisted schedule type: matching returned fields retains the office scheduling lock. Independent vendor-evidence verification is not integrated, so production submission and applied recovery are server-blocked. Existing visits and EVV evidence are never changed. Submission requires a separate release gate and scheduling reviewer role.

Create an inactive referral source

Create a source for the selected office without linking patients or sending outreach. This scope sets name and source type and explicitly creates it inactive. Parent, marketer, account manager and facility details are left unset. Activation and other details require a separate reviewed workflow.

Add a secondary patient contract

Review payer coverage authority before adding a secondary contract. The primary contract is not changed. Reference catalogs and patient placements on the selected start date must be available; an existing matching contract requires separate review. No referral is required. Submission remains disabled until deployment approval.

Replace a caregiver picture

Review an existing picture and retain the original under your approved policy. The independent reviewer supplies the same PNG or JPEG file, up to 2 MiB. Exact downloaded bytes must reconcile; transformed vendor images require investigation. An unavailable picture does not prove that no picture exists.

Add a related attachment

Add a file using a document type verified from an existing document belonging to this subject. First-document creation awaits a vendor-confirmed type lookup. An independent reviewer must select the exact same file. Maximum 2 MiB; file bytes are not saved in review records.

Replace an existing attachment

Retain the original under your approved records policy before proposing replacement. The second reviewer must verify that reference and select the exact replacement file. Only hashes and review details are saved here; each reviewer supplies the file locally. Maximum 2 MiB. The document type and description are preserved.

New caregiver medical due item

Prepare a first due item for a medical requirement. No completion, medical result or attachment is asserted. Existing records require a separate renewal review. Due dates come from your approved evidence, not an automated policy.

Patient clinical comment review

Change only an existing clinical comment under verified clinical authority. Allergies, order requirements and due-day settings are preserved. A reference to the clinical authority and independent review are required; source data and submission remain locked until their deployment approvals.

Document description review

Change only an existing document description. The server verifies ownership and reads the attachment (up to 2 MiB), compares its fingerprint, and resends identical bytes with the same file name and document type. File content is not stored in the review record or shown here. Missing or changed evidence blocks submission.

Document type change review

Update the name or status of an existing patient/caregiver document type. This affects the shared type, not only the reference document. The source description is preserved. Submission requires independent review and a separate deployment gate.

Availability change review

Propose one day’s availability using a complete source record. Blank source days, overnight intervals and unmapped values require vendor clarification. Each operation has a separate deployment gate.

Staffing evidence review

Compare patient choice and declines with selected caregivers’ source availability and visits. This review does not rank, assign, or confirm eligibility.

Supervisor investigations

Record outreach, contact outcomes and follow-up. Resolving a case does not change HHA, billing or payroll.

Prepare caregiver rate review

Read the selected current rate and prepare one hourly-rate proposal. A different administrator must review it after a source recheck. Preparing or approving a proposal does not submit UpdateCaregiverRate. A separate deployment gate, the approving reviewer, a fresh source comparison and verified source dates are required for one explicit submission. Currency and payroll authority must be reviewed before activation.

Change requests

Prepare a proposal for a different administrator to review. Approval does not submit a request. The specific workflow panels provide separately gated submission and reconciliation; generic visit/schedule proposals remain unsubmitted.
