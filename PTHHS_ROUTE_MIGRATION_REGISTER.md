**Reviewed:** September 10, 2026  
**Scope:** Contact, Careers, Blog, Client Feedback, service templates, and Get Started

| Area | Canonical destination | Decision | Publication state |
|---|---|---|---|
| Contact / Get Started | `/home-care-contact-us` | One canonical lead route | Published on modern shell |
| Legacy Set an Appointment | `/home-care-contact-us` | Permanent redirect; static fallback is `noindex,nofollow` | Retired |
| Careers | `/home-care-careers` | Current general-interest instructions only; no unsupported opening claims | Published on modern shell |
| Blog / information hub | `/home-care-blog` | Use verified service and official-resource links | Published on modern shell |
| Imported articles | `/home-care-blog` | All 24 imported posts remain quarantined | Zero retained posts |
| Blog pagination | `/home-care-blog` | Four obsolete pagination routes redirect to the current hub | Retired |
| Author/archive routes | None in repository | No route retained without reviewed content | Not published |
| Client Feedback | `/home-care-client-reviews` | No public comments or unapproved testimonials | Published on modern shell |
| Services | `/home-care-services` and five canonical detail routes | Shared modern service structure and scope controls | Published |

## Evidence required before restoring retired content

- Named content owner and current publication approval.
- Current authoritative sources for health-adjacent or program information.
- Confirmation that wording stays within non-medical personal assistance scope.
- Testimonial source, permission, attribution, accuracy, and privacy records.
- A unique purpose that does not duplicate the canonical destination.
